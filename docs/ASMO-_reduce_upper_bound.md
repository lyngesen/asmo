# Implementation details

First, the set $\hat{\mathcal{L}}^s$ is defined as the nondominated part of the Minkowski sum of the sets. This is done iteratively using the `reduce` function from itertools.

```Python
S_hat = [p_other for p_other in self.P if p.name != p_other.name]
other_lower_bounds = [p.L for p in S_hat]
# (combined) lower bound of other subproblems
L_hat = reduce(
    lambda L1, L2: SearchArea(L1 + L2).get_lower_bound(), other_lower_bounds
)
```
Note:
- `A.get_lower_bound()` returns the (weakly) nondominated part of the search area $A$, ie. this is a ND-filter $(\cdot)_N$.


Then the set $bd(\mathcal{U}\oplus \mathbb{R}^2_{\geqq}) \ominus \hat{\mathcal{L}}^s$ is calculated in the following line:

```python
Ugs = SearchArea(self.U + (-L_hat))
```

Note that the set $\mathcal{U}$ is represented by a `LineString` (see `asmo.py : _set_global_uper_bound()`. Using this we can represent the set $bd(\mathcal{U}\oplus \mathbb{R}^2_{\geqq})$ by a `LineString`, by adding two points $\begin{pmatrix}ul(\mathcal{U})_1\\ M\end{pmatrix}$ and $\begin{pmatrix}M \\lr(\mathcal{U})_2\end{pmatrix}$ for a sufficiently large $M$. (This is done in using the `extend_upper()` method defined for the `Bound` class).

Because of this the calculated `SearchArea` $Ugs$ will contain points generated by the choice of $M$, being far away from any area of interest. Therefor, we remov this part before continuing.
```python
Ugs = SearchArea(
    Ugs.geom.intersection(p.U.geom.envelope)
)  
```
Then we get the upper part of the shape - this is the application of the ()_wN-1 operator:
```python
Ugs = Ugs.get_upper_bound()
```

Finally, we merge using the rule from Ehrgott2007 Prop 2, and update the bound set for he Problem:
```python
Up_new = p.U.merge_upper_bounds(Ugs)
p.U = Up_new
```


# Optimizing the code

The problem: When running the ASMO-solver, most/almost all of the computational time is spent refining the upper bound sets.

Current implementation: The current implementation is written above. It works by computing each intermidiate set and then applying the filter getting the upper part of the polygon. That is:
1. Calculate $bd(\mathcal{U}\oplus \mathbb{R}^2_{\geqq}) \ominus \hat{\mathcal{L}}^s$ $\color{red}\text{(Very expensive)}$
2. Get upper part by applying $(\cdot)_{maxW}=(\cdot)_{wN^-1}$ operator.
3. Formulate as upper bound by applying the $(\cdot)_N$ operator.

New idea:
One can transform 1 and 2 to the problem of calculating the upper envelope of a set of monotone piecewise linear functions. This reformulation could allow for a faster algorithm since it used the fact that both $\mathcal{U}$ and $\hat{\mathcal{L}}^s$ are decreasing. Furthermore, we can use the fact that $\mathcal{U}$ is defined by the local Nadir points of $\hat{\mathcal{Y}} = (\oplus_{s\in \mathcal{S}}\hat{\mathcal{Y}}^s)_N$.
